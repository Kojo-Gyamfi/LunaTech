# E-Commerce App

A modern e-commerce web application built with Next.js, React, TypeScript, Tailwind CSS, and Zustand. The app includes product browsing, product details, cart management, checkout, order confirmation, support messaging, and Paystack payment integration.

## Features

- Product catalog with categories and price ranges
- Product detail pages
- Shopping cart slideout
- Checkout flow
- Order confirmation page
- Individual order pages
- Paystack payment initialization and verification
- Support contact form using email
- Responsive UI
- Toast notifications

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Zustand
- Lucide React
- Sonner
- Nodemailer
- Paystack API
